# Roadmap

Each milestone ends with something runnable and covered by automated tests.

| # | Milestone | Done when |
|---|---|---|
| **M0** ✅ | **Foundations:** workspace, CI, CC0 sample set, raw decode, CPU render to TIFF (`pe render`) | Every sample renders with plausible colour |
| **M1** ✅ | **Library and import:** SQLite catalog (folders, files, images, ratings/flags/labels), Add/Copy import with date-based folders, duplicate detection, metadata harvesting, embedded-preview thumbnails; SwiftUI grid and loupe | Verified: 5,000-file import (about 28 files/s with thumbnails); `kill -9` mid-import then resume, giving exactly 5,000 images with integrity OK. Follow-ups: background thumbnail building, faster reduced-scale JPEG decode, a measured scrolling benchmark |
| **M2** ✅ | **Raw to a pleasing image (CPU):** edge-directed demosaic + false-colour suppression (Bayer and X-Trans), highlight reconstruction, white balance (as-shot/auto/temperature-tint), wide-gamut working space, exposure, local shadows/highlights, contrast, filmic display transform with whites/blacks, point curve, orientation, golden-image regression tests | Default renders look natural across the sample set (see `docs/PIPELINE.md`; follow-ups listed there) |
| **M3** ✅ | **Non-destructive editing model:** typed settings schema, settings digest, command system, undo/redo, per-photo history (one step per gesture), snapshots, presets, copy/paste/sync; Develop panel with live preview | Each slider drag creates one history step; partial presets work. Follow-ups: editing JPEGs, an Auto Tone button, configurable paste groups |
| **M4** ✅ | **GPU pipeline and preview cache:** wgpu/Metal compute versions of every stage after demosaic, checked against the CPU reference; GPU live previews; 2048 px preview cache and 512 px thumbnails keyed by settings digest; background render worker with neighbour prefetch | Verified on an M1: 5–15 ms per slider render for a 36 MP raw (2048 px preview; 15 ms end to end in the app); GPU vs CPU mean and 99.9th-percentile ΔE₀₀ 0.000, never more than one 8-bit step. Follow-ups: GPU demosaic for full-resolution renders (1:1 zoom, faster export), zoom in the loupe |
| **M5** ✅ | **Export:** JPEG/TIFF/PNG (8/16-bit), colour spaces (sRGB, Display P3, Adobe RGB, ProPhoto) with our own ICC v4 profiles, linear-light resizing, output sharpening (screen/matte/glossy), metadata options, file naming and collision rules, presets | Verified: export vs on-screen render mean ΔE < 2; profiles read correctly by ColorSync (max error 0.5/255); EXIF read back by an independent parser. Follow-ups: user-supplied ICC profiles, parallel export of many small files, watermarks |
| **M6** ✅ | **Develop controls:** colour mixer, vibrance/saturation, black & white with mix, colour grading, texture/clarity/dehaze, noise reduction, sharpening, vignette, grain, manual lens corrections, crop/straighten/perspective with a crop overlay | Verified: every control has CPU and GPU implementations with parity cases on four cameras (mean ΔE₀₀ ≤ 0.001, never more than one 8-bit step); live GPU renders 4–35 ms on a 36 MP raw. Follow-ups: profile-based lens corrections (lens database), automatic upright, colour-wheel UI for grading, faster dehaze |
| **M7** ✅ | **Library depth:** collections and sets, rule-based smart collections, hierarchical keywords, search and filters, virtual copies, stacks | Verified: smart collections are evaluated at query time (always current), with tests for every rule family, nesting, and self-reference rejection; 5,000-photo library queries in 10–20 ms. Follow-ups: nested rule groups in the editor, custom sort order within collections, keyword synonyms and export of keywords to files |
| **M8** ✅ | **Masks:** linear, radial, brush, luminance and colour range masks with add/subtract/intersect/invert; local temperature, tint, exposure, contrast, highlights, shadows, whites, blacks, texture, clarity and saturation; Select Subject (Apple Vision, on-device) and Select Sky (this project's own heuristic) | Verified: mask values and composition match expected rasters in tests; CPU/GPU parity for every shape, combine mode and local adjustment (mean ΔE₀₀ 0.000); a stored raster mask changes exactly its half of an export. Follow-ups: masks edited on the cropped view, rotation handle for radial gradients, a trained sky model (the heuristic can take white walls at the top of the frame for overcast sky), local dehaze / noise / sharpening |
| M9 | **Migration (optional):** import an existing photo catalog and XMP develop settings (see `INTEROP.md`) | Folder/collection/keyword/rating structure imports exactly; looks are approximated |

## Algorithm sources (open literature)
Demosaic: RCD, AMaZE, Markesteijn. Local tone mapping: local Laplacian filters (Paris, Hasinoff, Kautz 2011). Texture/clarity: guided filter
(He, Sun, Tang 2010). Dehaze: dark channel prior (He, Sun, Tang 2009). Noise reduction: à-trous wavelets, non-local means. Colour: CIE
colorimetry, Oklab (Ottosson 2020), DNG Specification colour model. Grain: Newson et al. 2017. Colour management: LittleCMS.
